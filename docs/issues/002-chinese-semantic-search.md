# EVO-002：中文与跨语言查询的有效性，以及概念消歧

## 基本信息

- 类型：能力缺口
- 归类：核心设计议题
- 状态：设计梳理（不是旧代码修复任务）
- 原记录：中文整句和跨语言查询容易漏召回
- 核对：临时数据复现；2026-10-23；Evo `c94389b`

## 与重实现目标的关系

用户用中文整句提问，概念和字段可能使用英文。核心问题是：同一个意思换一种说法能否被找到，以及同名但口径不同的概念是否会被混淆。检索命中不等于业务含义正确。

正则取词导致漏召回是 Evo 的实现证据；这里不预设分词、向量模型或索引技术。

## 当前情况

browse 用正则取词，再按词重合和完整短语匹配排序。resolve 的名称匹配、别名匹配和上下文消歧也主要依赖字面信息。

## 不合理的地方

连续中文会被当成一个词。已有“收入”这个别名，也不代表带有“收入”的完整中文问题能命中；不同语言的同一含义也不会自动匹配。

## 影响

本体里明明有相关知识，Agent 仍可能查不到。换一种问法就可能改变结果。

## 核对依据与边界

临时构造名称 Revenue、别名“收入”的 Term：查“收入”命中 1 条，查“上个月收入为什么下降”命中 0 条。此例确认匹配限制，不代表所有中文查询都会失败。
